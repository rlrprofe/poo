# Glosario

| Término | Definición |
|---|---|
| **Abstracción** | Quedarse solo con las características relevantes de un elemento para el problema que se modela. |
| **Agregación** | Relación parte-todo débil: las partes pueden existir sin el todo. |
| **Asociación** | Conexión duradera entre objetos de dos clases; en Java, un atributo del otro tipo. |
| **Atributo** | Dato que guarda cada objeto. Todo lo que el objeto «sabe». |
| **Cardinalidad** (multiplicidad) | Número de objetos de una clase que se relacionan con un objeto de la otra (`1`, `0..1`, `*`, `1..*`...). |
| **Clase** | Plantilla que describe objetos con la misma estructura y comportamiento. Es módulo y tipo de dato. |
| **Clase abstracta** | Clase que no se puede instanciar y puede declarar métodos abstractos que implementan las subclases. |
| **Composición** | Relación parte-todo fuerte: las partes dependen del todo y desaparecen con él. |
| **Constructor** | Método especial que inicializa un objeto al crearlo. Se llama como la clase y no tiene tipo de retorno. |
| **Dependencia** | Uso puntual de una clase por otra (parámetro, variable local), sin guardarla como atributo. |
| **Encapsulación** | Ocultar los datos de un objeto y exponer solo los servicios que ofrece. También *ocultamiento de información*. |
| **Enlace dinámico** | Mecanismo por el que la versión de un método redefinido se elige en ejecución según la clase real del objeto. |
| **Estado** | Valor de los atributos de un objeto en un instante dado. |
| **Getter / setter** | Métodos que leen / modifican un atributo privado. El setter puede validar el valor. |
| **Herencia** | Mecanismo por el que una subclase reutiliza y especializa los atributos y métodos de una superclase. |
| **Identidad** | Característica que distingue a un objeto de cualquier otro, aunque tengan el mismo estado. |
| **Instancia** | Objeto creado a partir de una clase. |
| **Instanciación** | Creación de un objeto a partir de una clase (`new`). |
| **Interfaz** | Contrato: lista de métodos que una clase se compromete a ofrecer. |
| **Mensaje** | Petición que un objeto envía a otro para que ejecute un método. |
| **Método** | Procedimiento de una clase. Todo lo que el objeto «puede hacer». |
| **Método auxiliar** | Método privado que sirve de utilidad interna a otros métodos de la clase; no forma parte de su servicio. |
| **Método de clase** (`static`) | Método o atributo que pertenece a la clase y no a cada objeto; se usa con `NombreClase.miembro`. |
| **Navegabilidad** | Sentido en que se puede recorrer una asociación: unidireccional o bidireccional. |
| **Objeto** | Paquete de software con datos (atributos) y procedimientos (métodos). Instancia de una clase. |
| **Polimorfismo** | Capacidad de que objetos de clases distintas respondan al mismo mensaje cada uno a su manera. |
| **Redefinición** (*override*) | Reescribir en una subclase un método heredado, con la misma firma. |
| **Referencia** | «Dirección» de un objeto; es lo que guardan las variables de tipo clase. |
| **Sobrecarga** (*overload*) | Varios métodos con el mismo nombre y distintos parámetros en una misma clase. |
| **Subclase / superclase** | Clase que hereda / clase de la que se hereda. |
| **`super`** | Referencia a la superclase: `super(...)` invoca su constructor; `super.metodo()` su método. |
| **`this`** | Referencia al propio objeto que ejecuta el código. |
| **UML** | Lenguaje gráfico estándar para modelar sistemas orientados a objetos. |
